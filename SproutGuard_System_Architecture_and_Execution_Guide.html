End-to-End IoT & Edge AI Specification

SproutGuard: Edge AI Crop Stress Monitor

Complete Technical Architecture, Execution Lifecycle, Bottleneck Resolution & Codebase Audit

Target Hardware: NXP FRDM-MCXW71 (ARM Cortex-M33 @ 96 MHz)
Connectivity: Bluetooth Low Energy 5.3 (GATT Server)
Frontend Client: Android Hybrid App (Capacitor Native BLE + React 18)
Repository: edge_ai_crop_stress_detection (Branch: main)

1. Project Overview & Architecture

SproutGuard is an intelligent edge-computing agritech telemetry system engineered to detect physiological crop stress directly at the soil level prior to visible phenotypic degradation. The system eliminates cloud transmission dependency and latency by computing crop stress indices directly onboard an energy-efficient microcontroller and streaming formatted telemetry over Bluetooth Low Energy (BLE) to a cross-platform mobile dashboard.

Microcontroller & Sensing Rig

NXP FRDM-MCXW71 board reading analog soil probe (HW-103 on LPADC0), ambient light intensity (ALS-PT19 on LPADC0 Channel 2B), and ambient temperature & relative humidity (DHT11 single-wire bus on PTC0 / Arduino D2).

Onboard Edge AI Inference

C-based embedded inference evaluating multidimensional crop tolerance profiles (Tomato, Leafy Greens, Sweet Basil, Succulents) based on water deficit, heat shock, VPD, and solar intensity within 11.8 ms.

Low Energy Telemetry Server

Open, unauthenticated custom Wireless UART GATT profile broadcasting every 2 seconds via periodic OSA Timer Manager tasks to connected central devices without requiring OS-level PIN pairing.

Mobile Dashboard & UI

High-performance React 18 application wrapped in Capacitor. Features line-buffered packet reassembly, safe-area layout compliance, live radial stress gauges, and real-time biological health diagnostics.

2. Step-by-Step Project Execution Lifecycle

Below is the complete execution pipeline from physical power-on to live UI rendering:

Step 1: Board Boot & Peripheral Clock Gating
On hardware reset, main() invokes board initialization:
  • Core clock is ramped to 96 MHz via the internal FRO (Fast Reference Oscillator).
  • Clocks for Port A, Port B, Port C, and GPIO peripherals are enabled via CLOCK_EnableClock().
  • Cortex-M33 DWT (Data Watchpoint and Trace) cycle counter is activated via CoreDebug->DEMCR and DWT->CTRL to facilitate deterministic sub-microsecond timing for digital single-wire sensor protocols.
  • LPADC0 (Low Power ADC) peripheral clock is driven at 48 MHz with 3.3V VDD reference (kLPADC_ReferenceVoltageAlt1). Analog input pins (PTD1, PTD2, PTD3, PTA4, PTB2, PTB3) are isolated from digital buffers by muxing to kPORT_PinDisabledOrAnalog.
Step 2: BLE Subsystem & Wireless UART Advertisement
The Bluetooth Low Energy Host stack initializes:
  • Initializes link layer controller and host tasks.
  • Registers GATT Database containing the Wireless UART Service (01ff0100-ba5e-f4ee-5ca1-eb1e5e4b1ce0) and characteristic (01ff0101-ba5e-f4ee-5ca1-eb1e5e4b1ce0) configured with Notify and Read properties.
  • The Client Characteristic Configuration Descriptor (CCCD, UUID 0x2902) is exposed with open read/write permissions. Pairing and bonding flags are explicitly cleared (gAppUsePairing_d = 0, gAppUseBonding_d = 0).
  • The radio broadcasts non-connectable and connectable undirected advertising packets tagged with the complete local name "NXP_WU".
Step 3: Periodic Sensor Acquisition & Edge AI Inference Tick
A dedicated Timer Manager interval timer fires every 2 seconds via CropTelemetryTimerCallback():
  • DHT11 Digital Read: The MCU drives PTC0 LOW for 20 ms, releases HIGH for 30 μs, and switches to input with internal pull-up. It measures forty subsequent 50 μs/70 μs pulse durations using the DWT cycle counter with interrupts disabled to prevent RTOS jitter. Validates parity checksum (Byte0 + Byte1 + Byte2 + Byte3 == Byte4).
  • Soil Moisture ADC: LPADC0 triggers conversion on Channel 5 (PTD1 / A0) and Channel 6 (PTD2 / A1). Converts raw millivolts to percentage using HW-103 calibration (470 mV dry = 0%, 180 mV saturated = 100%).
  • Ambient Light Lux: Reads onboard ALS-PT19 phototransistor channel (ADC0 Channel 2 Side B) and scales millivolts to Lux.
  • Edge AI Stress Computation: CalculateCropStressScore() executes the multidimensional biological matrix to produce a real-time stress probability score (0.00 to 1.00).
Step 4: Safe JSON Formatting & GATT Chunk Dispatch
The telemetry packet is compiled and dispatched over the air:
  • To bypass embedded newlib-nano floating-point limitations, values are encoded into integer decimal components (whole and fractional tenths): 
    snprintf(json_buf, sizeof(json_buf),
         "{\"soil\":%d.%d,\"temp\":%d.%d,\"hum\":%d.%d,\"lux\":%lu,\"stress\":%d.%d}\r\n",
         soil_whole, soil_frac, temp_whole, temp_frac, hum_whole, hum_frac,
         (unsigned long)live_lux, stress_whole, stress_frac);
  • The full string is written into the local GATT DB attribute using GattDb_WriteAttribute().
  • If a central peer is connected, BleApp_SendUartStream() divides the string into ATT MTU-compatible chunks (typically 20 bytes) and transmits them sequentially via GattServer_SendInstantValueNotification().
Step 5: Mobile App Discovery, Connection & Subscription
The user opens the SproutGuard mobile app and initiates connection:
  • bleManager.js uses @capacitor-community/bluetooth-le on native Android (or Web Bluetooth API in browser) to scan for devices with the name NXP_WU.
  • Upon selection, the client establishes a direct GATT link, discovering the Wireless UART service.
  • The client writes 0x0001 to the CCCD descriptor of characteristic 01ff0101-ba5e-f4ee-5ca1-eb1e5e4b1ce0, enabling notifications on the MCU.
Step 6: Stream Reassembly, Resilient Parsing & UI Update
Notification chunks arrive asynchronously at the client:
  • _handleDataView() decodes incoming hex/binary payloads and appends them to a continuous string buffer (rxBuffer).
  • Line-buffered processor extracts tokens delimited by newline (\n), sanitizes any missing or broken JSON tokens, and invokes JSON.parse(). A secondary regex parser acts as a fail-safe.
  • The parsed telemetry object is dispatched to React state hooks in App.jsx, updating the Soil, Temperature, Humidity, Sunlight cards, radial stress meter, and agronomic diagnostic actions in real time.

3. Technical Challenges & Engineering Solutions

The following engineering hurdles were identified, audited, and resolved throughout the development lifecycle:

Symptom & Error Root Cause Diagnosis Implemented Permanent Solution
Android System Settings:
"Failed to connect to NXP_WU. The connection request was rejected." (HCI Reason 0x113)		 Pairing via the native Android OS Bluetooth menu initiates Classic Bluetooth Audio (A2DP) / HID profile lookups. The board is configured as an unauthenticated BLE GATT server; when PIN negotiation failed, the OS forcibly closed the L2CAP link. Disabled pairing/bonding entirely in MCU firmware (gAppUsePairing_d = 0, gAppUseBonding_d = 0). Enforced app-exclusive connection routing via Capacitor BLE client with visual instructions advising users to connect in-app.
Blank Widgets Lockout:
App displays "CONNECTED - LIVE", but all 5 dashboard cards remain stuck at --.		 Embedded Newlib-Nano Bug: In standard GCC ARM Embedded builds, snprintf() omits floating-point %f formatting by default to save flash. The MCU was transmitting {"soil":,"temp":,"hum":,"lux":859,"stress":}. The missing values caused JSON.parse() to crash with an unhandled SyntaxError every cycle. Refactored the MCU telemetry formatter to compute integer whole and fractional decimal digits explicitly (%d.%d). In the mobile frontend, added pre-parse JSON colon sanitization and robust regex fallback matching.
Link Drops & Read Error:
BLE connection drops within 6–10 seconds after connecting; log shows [BLE Native] read error.		 A client-side 3-second background polling interval was executing concurrent GattRead calls on the exact characteristic that was simultaneously streaming periodic notifications, provoking GATT transaction collisions and queue overflow in the Android Bluetooth stack. Decommissioned the automatic 3-second polling timer in bleManager.js. The link now relies exclusively on clean 2-second MCU push notifications, preserving the GATT read mechanism solely for on-demand manual sync button presses.
Duplicate BLE Packets:
Incoming notification stream showed corrupted and fragmented JSON lines arriving out of sequence.		 In wireless_uart.c, after splitting and sending the string through GattServer_SendInstantValueNotification(), an extraneous call to GattServer_SendNotification() was executed, inserting a redundant truncated packet into the radio transmit queue. Eliminated the duplicate notification dispatch from the loop, ensuring strictly ordered, single-transmission packet delivery.
DHT11 Communication Failures:
Zero temperature and humidity readings or intermittent checksum errors.		 Microsecond timing errors caused by RTOS interrupts preempting the single-wire timing loop, coupled with floating input pins lacking unmasked digital buffers in the port PIDR register. Wrapped the 40-bit transmission window in __disable_irq() and __enable_irq(). Explicitly unmasked input buffers via GPIO_PortInputEnable(), enabled internal pull-up resistors, and utilized hardware Cortex-M33 DWT cycle counters.
Header Layout Clipping:
App title and status pill overlapped with phone status bar (clock, battery, Wi-Fi icons).		 Missing safe-area inset padding on modern Android Edge-to-Edge displays with punch-hole cameras. Configured pt-[max(env(safe-area-inset-top),20px)] across the root header layout, providing clean 20px clearance below system status icons.

4. Key Source Code Breakdown

1. Firmware: crop-stress-frdm-mcxw71/source/wireless_uart.c

Core application logic and BLE GATT event controller. Key functions include:

  • CropTelemetryTimerCallback(void *pParam): 2-second periodic timer hook that samples DHT11, soil LPADC, and phototransistor, evaluates the Edge AI stress model, builds the integer-decimal formatted JSON buffer, writes the GATT DB attribute, and triggers BLE notifications.
  • BleApp_SendUartStream(uint8_t *pRecvStream, uint8_t streamSize): Inspects current ATT MTU (negotiated or default 23 bytes) and chunks outgoing packets into payload-safe frames (MTU − 3) dispatched via GattServer_SendInstantValueNotification().
  • BleApp_GattServerCallback(): Handles central descriptor writes (CCCD enabling notifications).

2. Firmware: crop-stress-frdm-mcxw71/source/board_adc.c & dht11.c

Hardware abstraction drivers for physical crop sensing:

  • crop_adc_init(): Configures LPADC0 with 48 MHz FRO clock, auto-calibration, and 3.3V reference voltage.
  • BOARD_ReadSoilAdcMv() & CalculateSoilMoisturePercent(): Reads capacitive sensor millivolts on PTD1/PTD2 and maps them to a calibrated volumetric moisture scale.
  • BOARD_ReadAmbientLightLux(): Reads the ALS-PT19 phototransistor channel and calculates illuminance.
  • DHT11_Read(float *hum, float *temp): Executes start pulse protocol, reads 40 bit-pulses using Cortex-M33 DWT hardware cycle timing, verifies 8-bit checksum, and caches last valid values to prevent dropouts.

3. Mobile Client: crop-stress-mobile/src/services/bleManager.js

Unified Bluetooth transport abstraction supporting both Native Android (via Capacitor) and Web Bluetooth:

  • connect(): Routes connection through native device scanner or Web Bluetooth dialog.
  • _handleDataView(rawVal): Normalizes DataView, Uint8Array, and string payloads from the native bridge.
  • _appendAndProcessRxString(chunk): Assembles incoming packet fragments into a FIFO buffer, splits strings on newline delimiters (\n), sanitizes syntax anomalies, and dispatches JSON objects to listeners.
  • _parseLine(str): Dual-engine parser that combines strict JSON evaluation with regex-based key-value extraction for fault tolerance.

4. Frontend Interface: crop-stress-mobile/src/App.jsx

Top-level React application component:

  • updateTelemetryUI(data): Receives telemetry payloads and updates individual state hooks (soilMoisture, temperature, humidity, light, liveStressScore) while preserving previous state during transient null frames.
  • diagnoseCropState(): Evaluates live telemetry against selected crop thresholds (Tomato, Basil, Greens, Succulent) to provide immediate agricultural remediation instructions.
Production Verification: The entire firmware binary was compiled with Ninja and verified on target hardware using LinkServer v26.9. The mobile application was packaged via Gradle into an Android APK and deployed to the connected physical device (OPPO Reno15c 5G). Live data verification confirmed continuous streaming of soil (98.6%), temperature (34.0°C), humidity (76.0%), sunlight (30 lx), and stress score (0.21).
